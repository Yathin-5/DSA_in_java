## Daily Routine

1. Study concepts for 45–60 minutes.
2. Implement the topic in Java for 60–90 minutes.
3. Solve 3–6 problems for 90–150 minutes.
4. Test edge cases and write complexity analysis.
5. Update [progress.md](./progress.md).
