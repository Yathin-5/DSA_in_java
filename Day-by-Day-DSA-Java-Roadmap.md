## Rules for Every Problem

1. Try independently before reading an explanation.
2. Write the brute-force and optimized approaches.
3. State time and auxiliary-space complexity.
4. Test empty input, one element, duplicates, and negative values where relevant.
5. Record the pattern and mistake in `progress.md`.
6. Keep every Java solution compilable.
